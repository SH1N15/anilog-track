# AniLog v0.6.0-beta.2

这是 Tauri 2 迁移线的第二个公开测试版。`v0.5.0` 继续作为稳定版和 GitHub Latest；安装测试版前建议先启用 WebDAV 同步或备份 Windows 安装目录中的 `data` 文件夹。

## 修复

- Windows 标准版和 Original 现在分别保持单实例。重复启动会恢复并聚焦已有窗口，不再生成多个后台进程。
- 隐藏启动、关闭到后台或托盘图标隐藏后，再次启动快捷方式仍会恢复已有窗口。
- 每日待看提醒时间使用复用的严格格式校验，非法值会安全恢复为默认时间。

## 新功能

- 季度新番可按本机时区分为星期一至星期日；暂未公布日程的作品单独列出。
- 可在“星期”和“全部”之间切换，搜索、类型和追番筛选在两种视图中保持一致。
- Windows 偏好设置新增托盘图标开关。隐藏图标不会停止后台 AniList/WebDAV 同步或系统通知。

## 安装说明

- Windows 测试版会覆盖对应 edition 的旧版安装，并保留安装目录中的 `data`。
- Android APK 使用与 `v0.5.0` 和 `v0.6.0-beta.1` 相同的发布证书，可直接覆盖升级。
- 标准版与 Original 的应用 ID、数据目录和安装包相互独立，可以同时安装。
- Windows 安装包未使用商业代码签名，SmartScreen 可能显示“未知发布者”。

## 已知限制

- 历史季度和未公布后续日程的作品可能归入“播出日待定”。
- 不同 Android 厂商可能延迟后台任务；请允许通知，并按需将电池策略设置为“不限制”。
- 这是预发布版本，不建议在没有备份的情况下替换唯一的数据副本。

## 验证

- Windows 标准版与 Original NSIS 构建通过。
- Android 标准版与 Original APK 构建、签名和包身份验证通过。
- 标准版与 Original Rust 测试通过，旧 Electron/Capacitor 回归测试通过。
- 两套 Tauri renderer 构建与生产依赖审计通过。
