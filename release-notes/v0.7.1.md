# AniLog v0.7.1

这是标准版 Bangumi 播出纠偏与跨端同步修复版，正式版不再标记为 beta/rc。

## 重要修复

- 逐集任务和下次更新日期以 Bangumi `/v0/episodes` 的 `sort` 与 `airdate` 为准，不再用首播日 `+7 天` 猜集数。
- 修复黄泉的使者、描绘直至生命尽头、尼古喵喵等因停播/改档导致的提前一集任务。
- AniList 可用时继续提供分钟级播出时间；只要 AniList 条目与 Bangumi 逐集表的集号匹配就采纳其完整 `airingAt`（包括延期、停播、改档后的日期），不再用过时的 Bangumi 日期级值阻断正确时间。
- AniList 暂时不可用时，标准版仍能清理未来假票、绑定 Bangumi `episodeId`，并使用最近一次可信分钟值；没有可信分钟值时降级为日期级时间，不伪造精确时刻。
- WebDAV 合并后、上传前再次套用本地 Bangumi episode 缓存，避免坚果云中的旧错误任务复活。
- Android 后台同步保持 Standard/Original 分层；Standard 的 Bangumi 日期权威不会被 AniList 分季数据覆盖。

## 发布范围

- Windows Standard / Original
- Android Standard / Original，仅 `arm64-v8a`
- Android `versionCode`: `9`

Windows 安装包未使用商业代码签名，系统可能显示“未知发布者”。
