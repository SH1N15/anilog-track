# AniLog v0.4.1

本次更新面向 AniLog Original。Windows 标准版和 Android 标准版仍使用 v0.4.0。

## 更新内容

- Windows Original 安装器新增 English / 简体中文语言选择。
- Windows Original 首次启动会继承安装语言，之后可在设置中随时切换；升级不会覆盖已有选择。
- 新增 Android Original，使用独立包名，可与 Android 标准版同时安装。
- Windows 与 Android Original 的界面、日期、提示、通知和后台提醒均支持中文与英文。
- 原名版继续只使用 AniList，不连接 Bangumi、`bangumi-data` 或第三方 Bangumi 反代。
- 英文界面默认按 English → Romaji → Japanese 选择番剧标题，用户可以修改首选顺序。

## 下载

- `AniLog-Original-Setup-0.4.1.exe`：Windows 10/11 x64，安装时选择语言。
- `AniLog-Original-Android-v0.4.1.apk`：Android 7.0 或更高版本，首次启动跟随系统语言。

Windows 安装包尚未进行商业代码签名，系统可能显示“未知发布者”。Android APK 使用项目发布密钥签名。

---

This release updates AniLog Original. The standard Windows and Android editions remain on v0.4.0.

- The Windows installer now offers English and Simplified Chinese.
- Windows and Android Original support switching the full interface language in Settings.
- Android Original uses a separate package name and can be installed alongside the standard Android edition.
- Both Original builds use AniList only and never connect to Bangumi or third-party Bangumi proxies.
- English title fallback order is English → Romaji → Japanese.
