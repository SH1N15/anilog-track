# AniLog v0.6.0

这是 AniLog 首个 Tauri 2 正式版。React 界面与 Rust 核心由 Windows 和 Android 共用，`v0.6.0` 取代 `v0.5.0` 成为 GitHub Latest。

## 正式版内容

- Windows 标准版与 Original 支持托盘后台、单实例、通知唤醒、每日待看提醒和可隐藏托盘图标。
- Android 使用 AlarmManager/WorkManager 进行系统级后台调度，无需应用进程常驻。
- Standard 使用本地映射与 Bangumi 补充中文标题；Original 在 Rust、前端和 Android 三层均不请求 Bangumi。
- Windows 与 Android 可通过用户自己的 WebDAV 双向同步追番、观看任务和取消追番记录，凭据保存在系统安全存储中。
- 新番列表支持按本机时区按星期分组，并可切换为完整列表。

## 安装说明

- Windows 附件支持 Windows 10/11 x64，安装包未使用商业代码签名，SmartScreen 可能显示“未知发布者”。
- Android 正式附件仅支持 `arm64-v8a`，要求 Android 7.0 或更高版本。
- Android `versionCode` 为 `7`，并使用与 v0.5.0、v0.6.0-beta.1 和 v0.6.0-beta.2 相同的发布证书，可覆盖升级。
- Standard 与 Original 使用独立的应用 ID 和数据目录，可以同时安装。
- 升级前建议启用 WebDAV 同步或备份 Windows 安装目录中的 `data` 文件夹。

## 验证

- Windows Standard/Original NSIS 均从最终 `main` 提交构建，内部版本为 `0.6.0`。
- Android Standard/Original APK 均从最终 `main` 提交构建，只包含 `lib/arm64-v8a/libanilog_lib.so`。
- 两套 Rust edition 测试、全部 renderer 构建、回归脚本和生产依赖审计通过。
