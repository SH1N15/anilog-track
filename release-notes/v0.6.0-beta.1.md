# AniLog v0.6.0-beta.1

这是 Tauri 2 架构的首个公开测试版。`v0.5.0` 继续作为稳定版和 GitHub Latest；测试前建议先启用 WebDAV 同步或备份安装目录中的 `data` 文件夹。

## 本次更新

- Windows 与 Android 迁移到 Tauri 2，共用 React 界面与 Rust 核心。
- Windows 关闭到托盘后销毁 WebView2，后台仅保留轻量 Rust 进程。
- 修复托盘重复窗口、左键菜单闪现、开机隐藏启动和关机退出错误。
- 点击 Windows 新番或待看通知会重新打开并聚焦主窗口。
- 迁移旧 Electron 本地状态及 WebDAV 配置，密码转存 Windows Credential Manager。
- Android 继续使用 AlarmManager、WorkManager、Keystore 和系统通知，无需应用进程常驻。
- 标准版继续使用 Bangumi 中文标题；Original 仅使用 AniList 标题。
- 标准版与 Original 均保留 WebDAV 双端同步、观看任务开关和每日待看提醒。
- 恢复绿色 `A` 图标，并统一两个版本侧栏的 `AniLog / 追番日程` 品牌显示。

## 安装说明

- Windows 测试版会覆盖对应的旧版安装，首次启动会自动尝试迁移数据。
- Android 必须使用与 `v0.5.0` 相同的发布证书签名，才能直接覆盖升级。
- 标准版与 Original 的应用 ID、数据目录和安装包相互独立，可以同时安装。
- Windows 安装包未使用商业代码签名，SmartScreen 可能显示“未知发布者”。

## 已知限制

- 仅保存在旧 Android WebView localStorage 中的已完成任务无法直接迁移；已启用 WebDAV 的用户可从同步文件恢复。
- 不同 Android 厂商可能延迟后台任务；请允许通知，并按需将电池策略设置为“不限制”。
- 这是预发布版本，不建议在没有备份的情况下替换唯一的数据副本。

## 验证

- Windows 标准版与 Original 人工验证通过。
- Android 标准版与 Original 人工验证通过。
- 标准版 Rust 17 项、Original Rust 16 项测试通过。
- 旧 Electron / Capacitor 11 组回归测试通过。
- 生产依赖审计未发现高危漏洞。
