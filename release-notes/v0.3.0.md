# AniLog v0.3.0

本版本提供两个可同时安装的中文界面版本。

## 下载选择

- `AniLog Setup 0.3.0.exe`：标准版，使用 Bangumi 中文标题
- `AniLog-Original-Setup-0.3.0.exe`：原名版，不连接 Bangumi，使用 AniList 英文、罗马字或日文标题

两个版本使用不同的应用 ID、默认安装目录和数据目录，追番记录与设置互不共享。

## 原名版

- 界面、托盘菜单、通知和任务文字继续使用中文
- 默认按“英文 → 罗马字 → 日文”选择番名
- 可在“偏好设置 → 番名显示”中改为英文、罗马字或日本語优先
- 切换标题偏好后，未手工改名的追番与已有任务会同步更新
- 不加载 `bangumi-data`，不注册 Bangumi 通信接口，不访问 Bangumi API 或第三方反代

## 构建与测试

- 新增标准版与原名版的独立构建、打包和开发命令
- CI 同时编译两个版本并检查 Bangumi 隔离
- 两个版本继续保留季度缓存、托盘后台、通知和观看任务功能
