# AniLog v0.3.1

修复后台同步后界面偶尔仍显示旧任务列表的问题，并完善取消追番时的任务清理规则。

## 修复内容

- 界面先订阅主进程状态更新，再读取初始状态，消除启动时的事件空档
- 防止较晚返回的旧状态覆盖已经收到的新任务状态
- 窗口从托盘恢复、重新获得焦点或重新可见时主动读取最新本地状态
- 主进程每次显示窗口时再次推送完整状态
- 本地状态刷新不会请求 AniList，不会增加 API 访问频率
- 从“我的追番”取消作品前显示确认提示，并告知将移除的待看任务数量
- 取消追番后只移除该作品的待看任务，已经完成的任务继续作为观看记录保留
- 升级后自动清理以前遗留下来的无追番待看任务，旧的已完成记录不受影响
