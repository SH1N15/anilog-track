# AniLog v0.2.7

首次 GitHub 公开版本。

## 主要功能

- 浏览不同年份和季度的新番时间表
- 使用 AniList 日程并通过 Bangumi 补充中文标题
- 自主选择追番，无需 AniList 或 Bangumi 账号
- 新一集播出后发送 Windows 通知并创建待看任务
- 逐集勾选已完成任务，所有个人数据仅保存在本机
- 最小化到托盘后释放界面进程，后台继续同步和提醒
- 显示并手动清理图片与网络缓存，不删除追番记录

## 本版改进

- 加入季度列表持久缓存、请求去重、刷新限流和失败退避
- 修复快速切换季度时旧请求覆盖当前列表的问题
- 改进 Bangumi 中文标题匹配和自定义提醒名称
- 数据、缓存和备份统一保存在安装目录的 `data` 文件夹
- 精简 Electron 语言包和生产依赖，降低安装体积
