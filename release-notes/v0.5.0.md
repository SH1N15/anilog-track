# AniLog v0.5.0

本次更新为 Windows 与 Android、标准版与 Original 统一加入每日待看任务提醒。

## 新功能

- 在“偏好设置 → 更新提醒”中启用每日待看提醒，并自定义本机提醒时间。
- 仅在存在待看任务时发送一次汇总通知；没有任务时保持安静。
- 通知最多预览三条任务，点击后直接打开观看任务页面。
- 同一天最多提醒一次；Windows 休眠恢复、应用重启以及 Android 设备重启后会检查是否需要补发。
- Android 使用本地原生任务摘要和系统调度，不要求应用常驻后台。
- 每日提醒只读取本地任务，不会增加 AniList、Bangumi 或 WebDAV 请求。

## 其他改进

- Windows 标准版安装包改用无空格文件名，避免 GitHub 自动重命名。
- 修正 Android 网络请求中的项目地址和版本标识。
- 改进设置页面在较窄窗口下的宽度约束。

## 下载

- `AniLog-Setup-0.5.0.exe`：Windows 标准版，使用 Bangumi 中文标题。
- `AniLog-Original-Setup-0.5.0.exe`：Windows Original，支持中文与英文，不连接 Bangumi。
- `AniLog-Android-v0.5.0.apk`：Android 标准版，使用 Bangumi 中文标题。
- `AniLog-Original-Android-v0.5.0.apk`：Android Original，支持中文与英文，不连接 Bangumi。

Windows 安装包尚未进行商业代码签名，系统可能显示“未知发布者”。Android APK 必须使用与旧版本相同的项目发布密钥签名，才能覆盖升级。

---

This release adds optional daily watch-task reminders to every Windows and Android edition.

- Choose a local reminder time under **Settings → Update alerts**.
- A summary is shown only when pending tasks exist, at most once per day.
- Up to three tasks are previewed, and tapping the notification opens Watch Tasks.
- Missed reminders are checked after Windows resumes or restarts and after Android restarts.
- Android uses system scheduling and a local native task summary without keeping the app process alive.
- Daily reminders use local data only and do not add AniList, Bangumi, or WebDAV requests.
