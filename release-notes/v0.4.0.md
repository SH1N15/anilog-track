# AniLog v0.4.0

本次更新加入 Windows 与 Android 之间的可选 WebDAV 双向同步，并修复 Windows 后台运行相关问题。

## 新功能

- 使用用户自己的通用 WebDAV 账户同步追番、观看任务和取消追番记录
- 支持坚果云等 WebDAV 服务，并提供连接测试与手动立即同步
- 支持离线修改后的数据合并和 ETag 冲突保护
- Windows 后台每 15 分钟同步一次；Android 在启动、恢复前台或数据修改时同步
- Windows 使用系统安全存储加密 WebDAV 密码，Android 使用系统 Keystore

## 修复

- Windows 开机自启时直接驻留托盘，不再自动显示主窗口
- Windows 关机或注销时先停止定时器及同步服务，避免退出报错

## 下载

- `AniLog Setup 0.4.0.exe`：Windows 标准版，使用 Bangumi 中文标题
- `AniLog-Original-Setup-0.4.0.exe`：Windows 原名版，不连接 Bangumi
- `AniLog-Android-v0.4.0.apk`：Android 标准版

Windows 安装包尚未进行商业代码签名，系统可能显示“未知发布者”。Android APK 使用与 v0.3.1 相同的项目发布密钥签名，可以直接覆盖升级。
